# VCell Org Retrospective (since September 2018)

A comprehensive historical retrospective and feature timeline of the **Virtual Cell
(VCell)** project across the **`virtualcell`** and **`cam-center`** GitHub
organizations, covering **2018-09-01 → 2026-06**. Written **code-first** — diffs,
releases, and tags are ground truth; PRs and the project board are corroborating
hints (VCell only adopted a PR-based workflow around 2022).
