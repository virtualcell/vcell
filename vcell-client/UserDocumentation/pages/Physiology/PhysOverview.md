# Physiology Overview

The Physiology contains the description of the biological components that comprise a BioModel:

- [Reaction Diagram](ReactDiagView.md) is a graphical editor used to create and edit
  [structures](../Appendix/Definitions.md#compartments),
  [reactions](../Appendix/Definitions.md#reactions) and
  [species](../Appendix/Definitions.md#species).
- [Reactions](ReactTabView.md) provides a table to view, create and edit
  [reactions](../Appendix/Definitions.md#reactions) and
  [reaction rules](../Appendix/Definitions.md#reaction-rules).
- [Structures](PhysStructTabView.md) provides a table to view and edit
  [membrane](../Appendix/Definitions.md#membrane) and [volume](../Appendix/Definitions.md#volume)
  compartments.
- [Species](SpeciesTabView.md) provides a table to view and edit species defined within structures;
  molecular details of species can also be edited here.
- [Molecules](Molecules.md) provides a table to view and define molecules, the building blocks for
  rule-based models.
- [Observables](Observables.md) provides a table to view and define observables, the outputs of
  rule-based models.

**Properties** for components of a BioModel can be found in the
[Object Properties pane](../PropertiesPanes/PropertiesPaneOverview.md) in the bottom right pane.
