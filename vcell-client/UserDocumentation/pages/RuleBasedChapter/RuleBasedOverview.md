# Overview of Rule-Based Features

The Virtual Cell Software provides an integrated environment to use
[rule-based](../Appendix/Definitions.md#rule-based) features among species and reactions in a VCell
Biomodel. [Molecules](../Physiology/Molecules.md), [Observables](../Physiology/Observables.md), and
[Reaction Rules](../Appendix/Definitions.md#reaction-rules) can be specified alongside
[reactions](../Appendix/Definitions.md#reactions) in the [Reactions](../Physiology/ReactTabView.md)
Table. Defining [Molecules](../Physiology/Molecules.md) allows the user to create species that have
[molecular details](../PropertiesPanes/PP_Species.md).

**Mixing Rule-based features and reaction networks**

Similar to the traditional BioModel, a rule-based BioModel consists of a model description
(Physiology) and one or more Applications. Any operations on species and reactions that are
supported in VCell can be used alongside rules. Specifically, species that are used as initial
[seed species](../Appendix/Definitions.md#seed-species) for rule-based models can be used as species
in reaction networks.

**Rule-based Applications**

Each [BioModel Application](../BioModelApplications/ApplicationOverview.md) allows the user to
define the quantitative conditions needed to define, run and visualize a numerical simulation. A
Rule-Based BioModel may have multiple Applications, solved using
[deterministic](../Appendix/Definitions.md#deterministic), or
[stochastic](../Appendix/Definitions.md#stochastic) approaches, and also supports
[network-free](../Appendix/Definitions.md#networkfree) and
[Langevin Dynamics](../Appendix/Definitions.md#langevin-dynamics) approaches. Each Application, in
turn, can have multiple Simulations, in which different numerical methods or conditions are used.

- [deterministic](../Appendix/Definitions.md#deterministic) or
  [stochastic](../Appendix/Definitions.md#stochastic)
  ([rule-based](../Appendix/Definitions.md#rule-based)) applications uses the
  [BioNetGen](../Appendix/Definitions.md#bionetgen) network-generation algorithm to first generate
  the complete network of species and reactions. The network is created by applying the set of
  reaction rules to the set of [seed species](../Appendix/Definitions.md#seed-species) with initial
  amounts specified in the
  [Species](../BioModelApplications/Specifications/SpeciesSpecifications.md) specification tab.
  [Network](../BioModelApplications/Specifications/NetworkSpecifications.md) specification
  parameters control the size of the network, which otherwise can become infinitely large. Generated
  species and reactions are viewed in the
  [Network](../BioModelApplications/Specifications/NetworkSpecifications.md) tab. After the user is
  satified with the network generated using the set of species and reaction rules, any
  determiministic or stochastic
  [simulation](../BioModelApplications/Simulations/simulations_overview.md) can be run.
- Network-Free simulations use the NFsim simulator, a stochastic-based simulator that and only
  creates the necessary species and reactions to satisfy the rules.
- [SpringSaLaD](../Appendix/Definitions.md#springsalad) simulations require the representation of
  molecules as a collection of impenetrable spheres (sites) linked by stiff springs. The diameter of
  each site and the distance between sites is specified. The
  [Langevin Dynamics](../Appendix/Definitions.md#langevin-dynamics) solver uses a stochastic
  approach to identify the position of each site based on diffusion as well as the molecular state
  defined by the reaction rules.

**Rule-Based MathModel**

MathModels for [deterministic](../Appendix/Definitions.md#deterministic) or
[stochastic](../Appendix/Definitions.md#stochastic) applications generated by a rule-based model
have a standard VCell structure with a full list of species and reactions, as well as observables
defined by functions. MathModels for [network-free](../Appendix/Definitions.md#networkfree)
application have a new syntax.
