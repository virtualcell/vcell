# UID Providers for Annotations

The [Annotations Properties Pane](../PropertiesPanes/PP_Annotations.md) accepts input of unique
identifiers from a set of providers depending on the model element selected.

All elements accept UIDs from

- PubMed
- DOI

**Models** also accept UIDs from

- BioModels Database
- Reactome
- NeuronDB
- MOdelDB at SenseLab

Structures also accept UIDS from

- Brenda
- Gene Ontology

Species and Molecules also accept UIDs from

- ChEBI
- KEGG Compound
- UniProt
- Enzyme Nomenclature
- Gene Ontology
- Reactome

Reactions also accept UIDs from

- KEGG Pathway
- KEGG Reaction
- Reactome
- Brenda
- IntAct

Additional UIDs are supported only when associated with imported models (e.g. from BioModels
Database), including

- InterPro
- Enzyme Nomenclature
- Ensembl
- KEGG Orthology
- KEGG Reaction
- Taxonomy
- ICD
- Mamo
- PubChem Compound
- Teddy
- PubChem Substance
- Doid
- Omim
- 3Dmet
- Cell Ontology
- Cas
- BTO
- Pato
- Pw
- Mod
- Fma
- Pr
- SBO
