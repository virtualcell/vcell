# VCell 7.7 — Stability Update

**Released to production:** 2026-04-20 (build 7.7.0.73), refined
to 7.7.0.77 on 2026-05-07.

The third and final release event on the VCell 7.7 line. After
the broad Feature Update landed in February 2026, several
production-only issues surfaced and were addressed in this
focused stability rollout. Themes: server self-recovery on
broker reconnect / out-of-memory / DNS-cache failure modes;
charset-aware reads of legacy Oracle CLOB content; thread-safety
in unit-of-measurement formatting; and final UI / NPE fixes
before the SpringSaLaD GA public release event in VCell 8.0.0.

## What's new

### Server self-recovery improvements

Three production wedge modes received targeted fixes:

- **JMS failover wedge.** A new `JmsFailoverWatchdog` bounds the
  reconnect attempts after an ActiveMQ broker reconnect cycle
  and triggers a process restart on persistent failure, ending
  a long-standing class of unresponsive-server incidents.
- **Out-of-memory handler.** Server JVMs now exit and dump heap
  on `OutOfMemoryError`, allowing the pod to be restarted
  automatically instead of remaining wedged.
- **DNS negative-cache fix.** The desktop client no longer caches
  failed DNS lookups, so transient DNS outages now recover
  automatically.

### Charset hygiene across legacy storage

Oracle CLOB reads were upgraded to use a charset-aware character
stream rather than the default platform charset, which had been
corrupting non-ASCII content in model annotations. A companion
set of XML hygiene fixes:

- UTF-8 is used explicitly when reading SBML / SED-ML XML.
- XML characters are validated in `name` and `sbmlName` setters,
  preventing control-character injection from imported documents.
- A new `scan-xml-control-chars` admin CLI detects malformed XML
  in stored documents.

### Unit-of-measurement thread-safety

A race condition in `InternalUnitDefinition.round` that produced
inconsistent unit strings during concurrent simulation generation
was fixed by serializing `DecimalFormat` access.

### Tooling additions

- `/loki-query` slash command for VCell log access across
  prod/stage/dev namespaces, with direct-kubectl fallback.
- Support-email parsing and triage tooling for processing user
  error reports.
- BioNetGen BNGL input preprocessor handles tilde-prefixed bare
  digits.

### SpringSaLaD beta — UI polish

> **SpringSaLaD availability in 7.7.** Throughout the 7.7 line
> SpringSaLaD was available under a beta-test feature flag (on by
> default in non-production deployments, off by default on the
> release site). The feature flag is removed in
> **[VCell 8.0.0](./8.0.0.md)**.

Final SpringSaLaD UI fixes before the 8.0.0 GA event:

- Graphic-editor fixes
- General UI bug fixes and enhancements
- Batch run results visualization (plots and tables) for general
  statistics (average, min/max, standard deviation) and cluster
  analysis (ACS, SD, ACO)

## Improvements

- Spatial results export selection changed to checkbox-based.
- Document-tree renaming bugs resolved.

## Bug fixes

- NPE in `ParticleMathMapping` for non-mass-action kinetics.
- NPE in `StochMathMapping` for symbol-less rate expressions.
- Linux (Ubuntu) FiniteVolume Solver buffer overflow on certain
  SBML/OMEX simulations.

## What's next

week after this release, but did not roll to production under
the 7.7 line — it is the bridge into the next public release event:
**VCell 8.0.0 — SpringSaLaD GA**. See
[VCell 8.0.0 release notes](./8.0.0.md).
