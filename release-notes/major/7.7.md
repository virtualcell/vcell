# VCell 7.7

The 7.7 line shipped to production in three named release events.
Each is its own marketing release with its own vcell.org accordion
entry; this file is an index into them.

| Release | Prod-rolled | Build(s) | Notes |
|---|---|---|---|
| [VCell 7.7 — Initial Release](./7.7-initial-release.md) | 2024-09-27 → 2025-02-17 | 7.7.0.0 / 7.7.0.9 / 7.7.0.15 | Java-native CLI plotting, SpringSaLaD UI redesign first pass, initial Quarkus REST endpoints, OIDC/Auth0, modernized HDF5, native pyvcell foundations |
| [VCell 7.7 — Feature Update](./7.7-feature-update.md) | 2026-02-04 | 7.7.0.47 | ~12 months of dev landing in one rollout: complete Quarkus REST endpoint set, install-without-admin, SpringSaLaD multi-run + SLURM, parameter estimation REST migration, generalized stochastic of non-mass-action, Pathway Commons upgrade, vcell-alert icon |
| [VCell 7.7 — Stability Update](./7.7-stability-update.md) | 2026-04-20 → 2026-05-07 | 7.7.0.73 / 7.7.0.77 | JMS failover watchdog, OOM exit handler, DNS negative-cache fix, charset-aware Oracle CLOB reads, thread-safety in unit formatting, NPE fixes in math mapping, BNGL preprocessor, /loki-query tooling |

Together these three events span the gap between **VCell 7.6**
(marketing release July 2024) and the upcoming
**VCell 8.0.0 — SpringSaLaD GA**.

> **Note on SpringSaLaD.** SpringSaLaD was released in VCell 7.7
> under a feature flag for beta testing — available to users who
> explicitly enabled it, and on by default in non-production
> deployments used by the team and beta testers. On the production
> release site the flag was off by default, so most end users did
> not see SpringSaLaD during 7.7. The feature flag is removed in
> **VCell 8.0.0**, where SpringSaLaD is enabled across all
> deployments as a first-class VCell modality.

The companion **post-7.6-marketing patches** to the 7.6 line
(7.6.0.20 → 7.6.0.50, July-September 2024 — covering Generalized
Stochastic of non-mass-action reactions, N5 file-format polish,
SED-ML compatibility expansions, and the initial SpringSaLaD
imports / partitions / help) are summarized in
[`CHANGELOG.md`](../../CHANGELOG.md) under the `[7.6-patches]`
section. They are folded into the relevant 7.7 release event
above where the user-facing thread continues.

For the engineer-track per-build detail, see
[`CHANGELOG.md`](../../CHANGELOG.md).
